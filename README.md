# Юрий Грачев — частная практика

Лендинг на React, TypeScript и Vite по макетам Figma 320, 390 и 1440 px. Без UI-библиотек. Сайт не опубликован. GitHub Actions проверяет код без деплоя.

## Разработка

Нужны Node.js 24 LTS и npm.

```sh
npm ci
npm run dev
```

- `npm run format` — форматирование Prettier.
- `npm run check` — проверка TypeScript.
- `npm test` — тесты интерактивного поведения.
- `npm run build` — production-сборка в `dist/`.
- `npm run preview` — локальный просмотр сборки.
- `npm run verify` — форматирование, типы, тесты и production-сборка.

## Структура

```text
src/
  app/                      # Точка входа, композиция страницы, общие стили
  assets/
    fonts/                  # Локальные WOFF2 и лицензии OFL
    images/                 # Адаптивные WebP и оригинальные SVG
  features/
    cookie-consent/         # Интерфейс и хранение согласия на аналитику
  sections/
    header/                 # У каждой секции свой компонент и CSS Module
    hero/
    work/                   # Аккордеоны отдельно в components/WorkTopics/
    about/
    office/
    publications/
    contact/
    footer/
  shared/
    config/                 # Контакты и параметры аналитики
    hooks/
    lib/analytics/
    ui/                     # Отложенная загрузка и обработка ошибок секций
  test/                     # Общая настройка DOM-тестов
config/                     # Генерация SEO-метаданных при сборке
public/                     # Favicon и исходный PDF политики
privacy.html                # Политика как самостоятельная HTML-страница
```

Компоненты и стили находятся рядом. Повторяющиеся данные вынесены в `*.data.ts`. JSX разбит на смысловые блоки; стиль закреплён Prettier и EditorConfig.

## Как менять содержимое

- Контакты: `src/shared/config/contacts.ts`. Telegram, MAX и email взяты из политики заказчика и проверены по макету.
- Тексты: компоненты секций; карточки, образование, темы работы и условия — соседние `*.data.ts`.
- Цвета и типографика: переменные в `src/app/styles/base.css`; локальные изменения — CSS Module нужной секции.
- Политика: `privacy.html`. Текст перенесён из предоставленного PDF без изменения формулировок; исходник доступен как `public/privacy.pdf`.
- Заголовки и описания: `index.html` и `privacy.html`. Canonical, Open Graph, sitemap и robots формирует `config/siteMetadata.ts`.

Нижние секции подключены через `React.lazy` и начинают загружаться за 400 px до появления. Якорная ссылка загружает свой раздел сразу. Анимации появления учитывают `prefers-reduced-motion`. На телефонах темы работы раскрываются по одной; на широком экране видны все три.

## Изображения и шрифты

Фотографии экспортированы из Figma: портрет — узел `228:160`, кабинет — `4:71`, книги в подвале — `28:17`. Во всех адаптивных макетах используются те же исходники; кадрирование задаётся стилями. SVG стрелок сохранены из макета без изменения геометрии.

Картинки имеют адаптивные варианты WebP. Первый портрет загружается с высоким приоритетом, остальные фотографии — лениво. Great Vibes, Literata и Manrope подключаются локально, используются только латиница и кириллица. Лицензии находятся рядом со шрифтами.

Чтобы обновить изображения, экспортируйте `portrait.png`, `office.png`, `books.png`, `chevron-up.svg` и `chevron-down.svg` в отдельную папку, затем запустите:

```sh
node scripts/optimize-images.mjs /absolute/path/to/exports
```

Минимальная ширина исходников: портрет 960 px, кабинет 1448 px, книги 1159 px. Оригинальные PNG не входят в production-сборку.

## GitHub Pages

Целевой репозиторий: `grachevelloper/yuri_grachev-landing`.

GitHub Pages отключён. Workflow `.github/workflows/ci.yml` запускает проверки при push в `main` и в pull request, без загрузки артефактов и публикации.

Конфигурация сборки подготовлена для проектного пути `/yuri_grachev-landing/`. Публикация требует отдельного согласования, включения Pages и добавления workflow деплоя.

Для настроек создайте `.env` по `.env.example` локально или добавьте Repository Variables в Settings → Secrets and variables → Actions:

| Переменная                 | Назначение                                         |
| -------------------------- | -------------------------------------------------- |
| `VITE_METRIKA_ID`          | TODO: ID реального счётчика Метрики                |
| `VITE_YANDEX_VERIFICATION` | TODO: код подтверждения Яндекс Вебмастера          |
| `VITE_SITE_URL`            | Полный URL сайта с завершающим `/`                 |
| `VITE_BASE_PATH`           | Путь публикации; по умолчанию берётся из URL сайта |

Метрика не загружается без корректного ID и согласия посетителя. Можно отказаться и изменить выбор через настройки cookies в подвале. Вебвизор отключён. Переменные применяются при следующей сборке; сами по себе они не включают публикацию.

Для своего домена настройте его в Pages и DNS, включите Enforce HTTPS, задайте `VITE_SITE_URL=https://ваш-домен/` и `VITE_BASE_PATH=/`. Домен пока не предоставлен. На проектном адресе файл `robots.txt` лежит в подпапке; корневой robots домена github.io контролируется корневым сайтом владельца.
